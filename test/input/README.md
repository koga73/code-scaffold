# App.Sample

This is a Sample app to be used as a template and reference

## Prerequisites:

- [NodeJS](https://nodejs.org/)
- [Visual Studio Code](https://visualstudio.microsoft.com/downloads/)

## Code Scaffold:

Run one of the following commands (replace "NewApp" with your application name)

### JavaScript Version (Default)

```bash
npx code-scaffold --input . --output ../App.NewApp --name NewApp
```

### TypeScript Version

```bash
npx code-scaffold --input . --output ../App.NewApp --name NewApp --language typescript
```

## Install

```bash
npm install
```

## Development

```bash
npm run start
```

### Build

```bash
npm run build
```
